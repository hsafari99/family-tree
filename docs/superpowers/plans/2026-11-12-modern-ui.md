# Modern UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the whole app look modern and polished, rebuild the tree canvas's look and interaction, and add two new tree views: a Fan chart and an Illustrated tree.

**Architecture:**
- The visual refresh is a token-first CSS rewrite in `apps/web/src/styles.css`, plus small shared components (icons, Toast, Skeleton, EmptyState).
- Canvas work stays inside `apps/web/src/canvas/`. The logic goes into pure, unit-tested functions (lineage, keyboard neighbours, collapse, animation tween, ahnentafel, descendant-tree layout), and thin React components render them.
- The two new views are plain SVG React components fed by two new graph modes, `ancestors` and `descendants`. They're computed on the server in `packages/shared/src/graph-view.ts`, so permissions and size limits stay where they are today.

**Tech Stack:** React 19, @xyflow/react 12.12.0, elkjs 0.12.0, Fastify 5, Zod 4, Vitest, Playwright. **No new dependencies.**

**Design reference:** the mockup the user approved, https://claude.ai/artifact/Ri4NmxuUxgqn2JSW1yjUQ2. The views to build are 1 · Illustrated tree, 2 · Fan chart and 4 · Hourglass. The Hourglass becomes the restyled Focus view.

## Ground rules (apply to every task)

**Branch and commits**
- Work on branch `modern-ui`, created from `ux-round-1`.
- Never push.
- Commit after each task. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit any of these: `.env.production`, `graft/`, `.ignore`, `.claude/settings.local.json`, `.vitest/`, `.prod-local/`, `.env*.local`.
- Never read or print `.env.development.local`.

**Dependencies and fonts**
- No new dependencies, and no CDN fonts or other external requests from the app.
- Fonts use a system stack: `"Inter", ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`. Headings use the same stack at weight 650–700 with tighter letter-spacing.
- Vite stays at 8.3.6.

**Theming and colour**
- Every colour is a token on `:root`, and dark mode redefines the tokens.
- Keep the existing `prefers-color-scheme` approach, and keep `Canvas`/`CanvasText` as the base so forced-colors mode still works.
- No hard-coded white, except behind the QR code.
- Text contrast is at least 4.5:1, and UI parts at least 3:1.

**Accessibility**
- Labels, keyboard use, visible focus, and `aria-live` for status messages.
- Hit targets are at least 24px.
- Every animation sits inside `@media (prefers-reduced-motion: no-preference)` or is skipped in JS when `matchMedia('(prefers-reduced-motion: reduce)').matches`.

**Forbidden**
- No `window.confirm` or `alert`.
- Only fixed, mapped error messages.

**Tests**
- Every behaviour change gets unit tests. User-visible flows also get E2E tests.
- Existing tests must stay green. Update a test only when the behaviour it pins has deliberately changed, and say so in the commit.

**Commands**
- Web unit tests: in `apps/web`, run `rtk proxy pnpm exec vitest run`. Read the "Tests N passed" line from the console; the `.vitest` JSON can be stale.
- API tests: in `apps/api`, run `rtk proxy pnpm exec vitest run`. Integration tests need the docker db.
- Shared: in `packages/shared`, run `rtk proxy pnpm exec vitest run`.
- Lint, format and typecheck: at the repo root, run `rtk proxy pnpm -r typecheck`, `rtk proxy pnpm lint` and `rtk proxy pnpm format:check`. Check `package.json` for the exact script names.
- E2E:
  - First run `AUTH_RATE_LIMIT_ENABLED=false docker compose up -d api`.
  - Then, from `e2e/`, run `rtk proxy pnpm exec playwright test --reporter=line`.
  - Afterwards, restore with `docker compose up -d api`.
- If the page goes blank in dev, run `docker compose restart web`.

**Visual checks**
- Check visual work with Playwright screenshots in light and dark, at 1280×800 and 390×844.
- Save them under the session scratchpad, never in the repo.
- Don't use Claude in Chrome.

### Task 9: Animated layout transitions

**Files:**
- Create: `apps/web/src/canvas/tween.ts` and `tween.test.ts`, `apps/web/src/canvas/useAnimatedNodes.ts`
- Modify: `FamilyCanvas.tsx`

**Tween**
- `tweenPositions(from: Map<id,{x,y}>, to: CanvasNode[], t: number): CanvasNode[]` uses ease-out cubic.
- A node not in `from` starts at its final place and is marked `className += ' is-entering'`; the CSS fades it in.
- A node not in `to` is dropped.

**The hook**
- `useAnimatedNodes(nodes, { duration: 320 })` keeps the last shown positions in a ref. On a new `nodes`, it drives `setShown` with rAF frames from the old positions to the new ones.
- It skips straight to the end when reduced motion is set, when there are 400 or more nodes, or on the first layout.
- Edges follow, because React Flow draws them from node positions.
- Fitting after a layout must wait until the animation ends. Have the hook return a promise or callback.

**Steps**

  - at t=0 the nodes sit at the old positions, and at t=1 at the new ones;

**The function**
- `collapseGraph(graph: TreeGraph, collapsed: ReadonlySet<string>): { graph: TreeGraph; hiddenCount: Map<string, number> }`
  - For each collapsed person, hide every descendant reached through unions where they're a partner, plus those descendants' partners.
  - A person stays shown if they can be reached from the focus or root without going through a collapsed person.

- A collapsed person shows "+N" with "Show N hidden descendants of X".

**Storing state**
- Per tree in localStorage under `ft.collapsed.<treeId>`, wrapped in try/catch, so a refresh keeps it.
- Unknown ids are ignored.
